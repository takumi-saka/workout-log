# 筋トレログ

自分用の筋トレ記録アプリです。スマホのホーム画面に置いて使う Web アプリ（PWA）で、記録はスマホのブラウザの中にだけ保存します。外のサーバーには送りません。

公開先: https://takumi-saka.github.io/workout-log/ （main に入れると GitHub Actions で自動的に公開されます）

## スマホで使う

1. スマホの Chrome で公開先の URL を開きます。
2. メニューの「ホーム画面に追加」（または「アプリをインストール」）を押します。
3. ホーム画面のアイコンから開くと、全画面で開きます。電波がなくても開けます。

新しい版を公開すると、次にアプリを開いたときから新しい版になります。

## できること

- Day（A・B・C など）を選んで記録します。開いたときは、前回の次の Day と今日の日付が入っています。日付はカレンダーから変えられます。
- 重さと回数は −/+ で変えるほか、数字を押して直接入れられます（81.25kg のような細かい値も入ります）。
- 完了を押すと休憩のカウントダウンが始まり、終わると振動で知らせます。休憩の長さは種目ごとに決められます。
- 時間は「スタート」で計り始めます。押し忘れても、1セット目を完了したときに計り始めます。始めた時刻はあとから直せます。
- 自己ベストを出すと、その場で印が出ます。
- その日の種目の順番は自由です。下の一覧で種目を押すと切り替わります。今日だけの入れ替え・追加・スキップもできます。
- 「記録を終える」で、今日のまとめ（セット数・時間・自己ベスト・前回より伸びた種目）を見て、評価とメモを入れて保存します。
- 履歴（カレンダーと一覧。押すと直せます）、進捗（Day ごとの最大重量の合計と、種目ごとの推移）、メニューの編集（Day と種目の追加・削除・並び替え）。
- CSV の書き出し、LLM に貼るためのまとめのコピー、バックアップの書き出し・共有・復元。

前の版（保存キー `workout-log-v1`）の記録は、新しい版を初めて開いたときに自動で引き継ぎます。前の版のデータには手を付けません。

## 作り

ビルドの手順はありません。`app/` の中身をそのまま公開しています。

- `app/index.html` … 画面の枠
- `app/styles/app.css` … 見た目
- `app/src/` … 処理
  - `model.js`（計算）、`store.js`（保存）、`migrate.js`（前の版からの引き継ぎ）、`export.js`（CSV と LLM 用のまとめ）
  - `menu-default.js`（最初のメニュー）
  - `ui.js`（下から出る画面・数字キーなどの部品）、`screens/`（画面ごとの処理）
- `app/sw.js` … 電波がなくても開くための仕組み。ファイルを足したら一覧にも足し、版（`VERSION`）を上げます。`app/src/version.js` の版もそろえます。

## 手元で動かす・確かめる

```sh
python3 -m http.server 4174 --directory app
# ブラウザで http://localhost:4174 を開く
```

テスト:

```sh
node --test tests/          # 計算・引き継ぎ・書き出しのテスト
python3 -m http.server 4178 # リポジトリのルートを配信して、
# http://localhost:4178/tests/ui.html を開くと画面のテストが動きます
```

## スマホのアプリ（APK）

main に入れるたびに、GitHub がスマホに入れるアプリのファイルを作ります（`.github/workflows/android.yml`、中身は `android/`）。

- ダウンロード: https://github.com/takumi-saka/workout-log/releases/download/app-latest/workout-log.apk
- アプリは上の公開先のページを開くだけの作りです。ページを新しくすれば、入れ直さなくてもアプリの中身が新しくなります。一度開けば電波がなくても動きます。
- 記録はアプリの中に保存します（Chrome で開いたときの記録とは別です）。
